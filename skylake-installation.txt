SKYLAKE LIGHTING SYSTEM FOR SNAPMAKER U1
========================================

TEST VERSION: CONFIG-ONLY PE15 OWNERSHIP METHOD

RUNTIME FILES
-------------
1. skylake-moonraker.conf
   Connects Moonraker to WLED.

2. skylake-wled.cfg
   Keeps the top-cover 24 V rail enabled and mirrors the stock U1 cavity light
   to WLED.

No Python patch, Klipper extra, slicer change, start G-code change, or end
G-code change is used.


EXPECTED BEHAVIOR
-----------------
- The top-cover port's 24 V rail turns on when Klipper configures the MCU.
- The rail stays on while Klipper operates.
- PE15 uses shutdown_value: 0 during an MCU/Klipper shutdown.
- The stock cavity-light switch remains the WLED master control.
- Cavity light OFF turns WLED OFF.
- Cavity light ON loads WLED preset 1.
- PA7 remains assigned to the stock purifier for genuine-cover detection.
- PA8/PA9 fan control, feedback, UI controls, and purifier modes remain stock.

KNOWN TRADEOFF
--------------
The stock purifier no longer owns a power_enable_pin. When it changes fan speed,
the current Snapmaker implementation may write this non-fatal log message:

    [purifier] power enable pin not exist!

The published source logs the message and returns rather than raising a command
error. Official-cover fan and UI behavior must still be tested before treating
this as a finished installation.


BEFORE INSTALLATION
-------------------
1. Save your desired white-light configuration as WLED preset 1.
2. Give WLED a static IP address or DHCP reservation.
3. Confirm the lighting, connector, wiring, fuse protection, and load are rated
   for 24 V and do not exceed the printer port or power-supply ratings.
4. Do not connect, disconnect, or probe wiring while energized.
5. Do not make or test these changes during a print.


STEP 1: ENABLE ADVANCED MODE
----------------------------
On the physical U1 touchscreen, open:

    Settings > Maintenance > Advanced Mode

Accept the warning and enable it. Refresh Fluidd. The configuration-file lock
icons should disappear.


STEP 2: CONFIGURE WLED
----------------------
Open skylake-moonraker.conf and change:

    address: 192.168.0.123
    chain_count: 20

Use the WLED controller's fixed address and actual LED count. Leave:

    initial_preset: 1

unchanged to use preset 1 as the white working light.


STEP 3: BACK UP STOCK FILES
---------------------------
Download printer.cfg and moonraker.conf from Fluidd. Keep the backups somewhere
other than the printer.


STEP 4: UPLOAD THE SKYLAKE FILES
--------------------------------
Upload these beside printer.cfg and moonraker.conf:

- skylake-moonraker.conf
- skylake-wled.cfg

Do not restart yet.


STEP 5: TRANSFER PE15 OWNERSHIP
-------------------------------
Find the stock [purifier] section in printer.cfg:

    [purifier]
    exhaust_pin: !PA8
    inner_pin: !PA9
    power_enable_pin: PE15
    power_det_pin: PA7

Comment out only the PE15 line:

    # power_enable_pin: PE15

Do not alter the rest of [purifier].

This is mandatory because skylake-wled.cfg contains:

    [output_pin skylake_24v]
    pin: PE15
    value: 1
    shutdown_value: 0

PE15 must never be assigned to both objects.


STEP 6: ADD THE KLIPPER INCLUDE
-------------------------------
Add this near the include statements in printer.cfg:

    [include skylake-wled.cfg]

Before restarting, confirm both changes are present:

1. power_enable_pin: PE15 is commented out in [purifier].
2. [include skylake-wled.cfg] is present.


STEP 7: ADD THE MOONRAKER INCLUDE
---------------------------------
Add this to moonraker.conf:

    [include skylake-moonraker.conf]


STEP 8: RESTART
---------------
1. Restart Moonraker.
2. Perform a Klipper Firmware Restart.
3. Confirm Fluidd returns to Ready without a configuration error.

If PE15 is reported as used multiple times, the stock purifier line was not
commented out correctly. Follow FAST RECOVERY below.


STEP 9: TEST 24 V BEFORE CONNECTING THE LOAD
---------------------------------------------
Using verified connector pinout and appropriately rated equipment:

1. Boot with no official top cover connected.
2. Verify approximately 24 V between the correct 24 V and GND pins.
3. Wait several minutes and confirm voltage remains present.
4. Toggle the stock cavity light; the 24 V rail should remain present.
5. Perform a Klipper restart and confirm the rail safely cycles and returns.


STEP 10: TEST WLED
------------------
After connecting the correctly rated lighting system:

1. Allow WLED time to boot and join Wi-Fi.
2. Turn the U1 cavity light OFF; WLED should turn off within about one second.
3. Turn the cavity light ON; WLED should load preset 1 within about one second.
4. Repeat several times.


STEP 11: TEST THE OFFICIAL TOP COVER
------------------------------------
If available, test every stock function under supervision:

1. Confirm genuine-cover detection changes normally.
2. Command both fans off and confirm they stop.
3. Confirm 24 V remains present with fans off.
4. Command each fan at several speeds.
5. Confirm tach/status feedback remains correct.
6. Exercise stock purifier UI controls and automatic behavior.
7. Review klippy.log for unexpected errors beyond the known message above.

Do not proceed to unattended printing if stock behavior changes materially.


MANUAL DIAGNOSTIC COMMAND
-------------------------
The PE15 output can be reaffirmed from Fluidd:

    SET_PIN PIN=skylake_24v VALUE=1

Do not set it to zero while the lighting system is operating.


FAST RECOVERY
-------------
If Klipper does not return to Ready:

1. Remove or comment out:

       [include skylake-wled.cfg]

2. Restore the stock purifier line:

       power_enable_pin: PE15

3. Perform a Firmware Restart.

If Moonraker fails separately, remove or comment out:

    [include skylake-moonraker.conf]

then restart Moonraker.


COMPLETE REMOVAL
----------------
1. Remove [include skylake-wled.cfg] from printer.cfg.
2. Restore power_enable_pin: PE15 in [purifier].
3. Remove [include skylake-moonraker.conf] from moonraker.conf.
4. Restart Moonraker and Klipper.
5. Delete the two Skylake files if desired.


FIRMWARE UPDATES
----------------
A firmware update may replace printer.cfg or moonraker.conf. After updating,
verify whether [purifier] owns PE15 before re-enabling the Skylake include.
Never enable skylake-wled.cfg while the stock purifier also owns PE15.
